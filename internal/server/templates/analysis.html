Historical Analysis

Server-rendered charts over height-bucketed block data. Pick a view:

  • Algo Distribution - block count per pow-algo (RXM/RXT/C29/SHA3X) over height buckets.
  • Pool Share - block count per pool (top pools + "other"/"unknown") over height buckets. Own-pool/multi-node tag families (e.g. Jagtech) are merged into one series - see Pool Algo Breakdown.
  • Pool Algo Breakdown - for a merged pool series from the pool-share mapping (?pool=), block count per pow-algo (RXM/RXT/C29/SHA3X) over height buckets.
  • Block Time - median inter-block time over height buckets, plus mean/median/stddev/max summary.
  • Difficulty - average difficulty over height buckets (hashrate proxy).
